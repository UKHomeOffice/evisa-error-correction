# E2E tests

These Playwright tests use `playwright-bdd` to run the EEC journeys described in
Gherkin feature files.

## Structure

```text
e2e-tests/
  features/       Gherkin journeys and form validation scenarios
  fixture/        Playwright fixture that creates and provides page objects
  pages/          Page objects for individual EEC form pages
  steps/          Step definitions that connect Gherkin steps to page objects
  utility-helper/ Shared test constants, including the test email configuration
```

`playwright.config.ts` at the repository root configures Chromium, loads the
root `.env` file, and points `playwright-bdd` at the feature and step files.
BDD-generated test files are written to `.features-gen/` and are generated by
the test command.

## Run locally against UAT

### Prerequisites

- Node.js matching the `engines.node` range in the root `package.json`
- Yarn
- Access to the EEC UAT environment and an approved test email address

### Configure the environment

Create or update `.env` in the **repository root** (next to `package.json`):

```dotenv
PLAYWRIGHT_BASE_URL=https://eec.uat.sas-notprod.homeoffice.gov.uk
SAS_HOF_EMAIL=<approved-test-email-address>
```

`PLAYWRIGHT_BASE_URL` selects the UAT site. When it is set, Playwright does not
start a local application server. Without it, the configuration defaults to
localhost and attempts to start the local development server instead.

`SAS_HOF_EMAIL` is required by the E2E test constants. Use an approved test
mailbox, not a real user's address. The root `.gitignore` excludes `.env`; do
not commit it.

### Install and run

From the repository root:

```bash
yarn install
yarn playwright install chromium
yarn test:e2e
```

`yarn test:e2e` generates the BDD tests and runs the E2E suite against the URL
in `PLAYWRIGHT_BASE_URL`. The suite submits test journeys to UAT, so only run it
against an environment and with test data you are authorized to use.

Other available commands:

```bash
yarn test:e2e:headed  # Run with the Playwright headed option
yarn test:e2e:debug   # Run with the Playwright debugger
yarn test:e2e:report  # Open the most recent HTML report
```
